One-time setup

The editor saves results by committing data.json to your GitHub repository. For that it needs a GitHub access token. Your token is encrypted with the password below and stored in the repository as editor-key.json; the password never leaves your device.

The lock file is public, so anyone could try to guess the password offline. Use a long passphrase (for example four or five random words), a token that expires, and a token limited to this one repository.
